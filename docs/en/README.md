# Hows documentation

Hows records what you click and turns it into an illustrated step-by-step guide. Guides stay on your PC unless you share them or save them into a synced folder. These pages explain how to install and use it.

## Getting started

1. [Install Hows](install.md): installers, portable ZIP, updates, and removal.
2. [The SmartScreen warning](smartscreen.md): why Windows warns about Hows and how to continue.
3. [Record a guide](recording.md): how to start, pause, and stop a recording, and what becomes a step.
4. [Edit and annotate](editing.md): edit step text, reorder steps, and mark up screenshots.
5. [Export and share](export.md): HTML, PDF, Markdown, JSON, and the `.steps` file.
