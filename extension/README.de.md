# Browser-Erweiterung (geplant)

Dieser Ordner ist für eine WebExtension reserviert (Manifest V3, eine Codebasis für Chrome, Edge und Firefox) mit einem Native-Messaging-Host.

Auch ohne sie funktionieren Aufnahmen im Browser schon über UI Automation. Die Erweiterung würde sie genauer machen: CSS-Selektoren, ARIA-Beschriftungen, Adressen und Titel von Seiten. Das `.steps`-Format hält die Felder dafür frei (`selector`, `aria_label`, `url`, `page_title`, siehe [Das `.steps`-Dateiformat](../docs/de/file-format.md#element)).

Umgesetzt ist noch nichts. Wenn du daran arbeiten willst, eröffne zuerst ein Issue, damit wir uns auf das Nachrichtenprotokoll einigen.
